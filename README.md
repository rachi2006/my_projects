### 🎯 SkillPath

**SkillPath** is a developer learning and skill-tracking platform designed to help users build structured learning paths based on their goals. It provides a centralized environment to organize skills, track learning progress, and follow a personalized development roadmap.

**Tech Stack:** Python · Flask · MongoDB · HTML · CSS · JavaScript
